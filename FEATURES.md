# Features
swe manages the AI coding CLIs on a machine (Claude Code, Codex, Gemini, Cursor, opencode and more) through one `swe` CLI, a macOS app, an iPhone app and a web app served by its remote-control hub.

## CLI
- **Help**: Print every command grouped by category, or one command's detailed help. Status: stable. Surface: CLI. Entry point: `swe help [command]`, `swe <command> --help`. Tests: `tests/test_cli.py`, `tests/test_drift.py`.
- **Version**: Print the installed swe version. Status: stable. Surface: CLI. Entry point: `swe version` (`-v`, `--version`). Tests: `tests/test_cli.py`.
- **Report a bug from the terminal**: Open a GitHub bug report with your swe, Python and OS versions filled in. Status: stable. Surface: CLI. Entry point: `swe bug`. Tests: `tests/test_bug.py`.
- **Shell autocomplete**: Generate and inject tab completion for zsh, bash or fish covering subcommands, registered tool names and aliases, tags and flags; safe to re-run. Status: stable. Surface: CLI. Entry point: `swe autocomplete [zsh|bash|fish]`. Tests: `tests/test_completion.py`, `tests/test_completion_scripts.py`.
- **Configuration**: Print, get, set, unset, edit and validate swe's credential-free settings in `~/.swe/config/config.json`; `check` also reports setup and secret safety. Status: stable. Surface: CLI. Entry point: `swe config [get|set|unset|edit|check]`. Tests: `tests/test_config_commands.py`, `tests/test_configuration.py`, `tests/test_corrupt_config.py`.
- **Find shared assets**: See where AGENTS.md, skills, plugins and MCP servers live and which harnesses link to them, as counts or every row (`--full`), by scope (`--scope=global|local|all`) and harness activity (`--harness=active|all`); read only, and a hidden archived row is always announced. Status: stable. Surface: CLI. Entry point: `swe find [amd|skills|plugins|mcps]`. Tests: `tests/test_find.py`, `tests/test_find_summary.py`, `tests/test_find_roots.py`, `tests/test_find_plugins.py`, `tests/test_find_mcps.py`, `tests/test_find_harness_filter.py`.
- **Browse shared assets**: Walk find's rows with the arrow keys and descend into them. Status: stable. Surface: CLI. Entry point: `swe find plugins -i`. Tests: `tests/test_find_browser.py`.
- **Tags and aliases**: List every tag with the tools that carry it, and every short alias with its tool. Status: stable. Surface: CLI. Entry point: `swe tags`, `swe aliases`. Tests: `tests/test_harness_commands.py`.
- **Machine-readable output**: Get one `{schema, data}` JSON document from the listing commands, the contract the Mac app reads. Status: stable. Surface: CLI. Entry point: `--json` on `swe list`, `swe session`, `swe skills`, `swe mcp`, `swe hooks stats` and others; shapes in `docs/json-contracts.md`. Tests: `tests/test_json_output.py`, `tests/test_json_envelope.py`, `app/mac/Tests/SWECoreTests/SweContractTests.swift`.
- **Insights**: An audit of how the agentic workflow is going (outcome trend, first-pass rate, guard refusals, dead MCP entries, unwired hooks) from the session index; the passive counters already run after each index pass, the surfaces are not built (`docs/insights.md`). Status: planned. Surface: CLI. Entry point: guessing: `swe insights`. Tests: `tests/test_insights_t0.py`, `tests/test_insights_metrics.py`, `tests/test_insights_store.py`.

## Harnesses
- **List harnesses**: List every registered AI coding CLI, starred first, filtered by tag; `--usage` adds the 100-day session count and remaining quota (the only part that touches the network), `--links` the AGENTS.md and skills link status, `-n` bypasses caches. Status: stable. Surface: CLI. Entry point: `swe list` (`ls`, `swe harness list`). Tests: `tests/test_harness_commands.py`, `tests/test_harness_command_behaviors.py`, `tests/test_registry_state.py`.
- **Choose list columns**: Pick which columns `swe list` shows (NAME and the star stay on) and read what the link glyphs mean. Status: stable. Surface: CLI. Entry point: `swe list edit [--reset]`, `swe list legend`. Tests: `tests/test_list_columns.py`.
- **Harness details**: Show one tool's display name, command, version, path, tags and aliases. Status: stable. Surface: CLI. Entry point: `swe info <name|alias>`. Tests: `tests/test_harness_commands.py`.
- **Register, edit and remove harnesses**: Add or update a tool, edit its command, display name, description, aliases, tags, version and notes by flag or interactively (`--json` never prompts), review every harness at once, or drop one from the registry without uninstalling it. Status: stable. Surface: CLI. Entry point: `swe add`, `swe edit <name> [--field=val]`, `swe harness edit`, `swe remove` (`rm`). Tests: `tests/test_harness_edit.py`, `tests/test_add_json.py`, `tests/test_harness_add_interactive.py`, `tests/test_harness_registry.py`.
- **Discover harnesses**: Scan PATH and home folders for unregistered AI coding CLIs as a dry run, then add the high-confidence matches (`--apply`) or every match (`--apply-all`). Status: stable. Surface: CLI. Entry point: `swe harness discover` (`swe discover`). Tests: `tests/test_harness_discover.py`, `tests/test_harness_discover_command.py`.
- **Check installs**: Probe each tool's live version and refresh the registry. Status: stable. Surface: CLI. Entry point: `swe check`. Tests: `tests/test_harness_commands.py`.
- **Install a harness**: List a harness's install command per package manager, or run one with `--via=<manager>`. Status: stable. Surface: CLI. Entry point: `swe install <name>`. Tests: `tests/test_installers.py`, `tests/test_harness_doctor_install.py`.
- **Star a harness**: Toggle a favourite, which pins it to the top of `swe list` and opts it into usage polling. Status: stable. Surface: CLI. Entry point: `swe harness star <name>`. Tests: `tests/test_harness_stars.py`, `tests/test_star_toggle.py`.
- **Archive a harness**: Shelve a harness you ruled out, with a reason; its rows drop out of the default views. Status: stable. Surface: CLI. Entry point: `swe harness archive <name> [why]`. Tests: `tests/test_archive.py`.
- **Launch a harness**: Start any tool by name or alias with extra args passed straight through (the process is replaced); `--provider=<slug>` launches with a stored provider key. Status: stable. Surface: CLI. Entry point: `swe use <name|alias> [args…]` (`run`). Tests: `tests/test_harness_command_behaviors.py`, `tests/test_remote_provider_launch.py`.
- **Harnesses page**: Browse, star, archive, restore and edit harnesses, detect and register new ones, or add a custom one through a form. Status: stable. Surface: macOS. Entry point: Harnesses page. Tests: `app/mac/Tests/SWECoreTests/HarnessesModelTests.swift`, `app/mac/Tests/SWECoreTests/HarnessEditTests.swift`, `app/mac/Tests/SWEAppUITests/AddHarnessPathTests.swift`.
- **Harnesses page**: Every registered harness, archived included, with In use and Archived scopes, search, starred-first order and the fold for unstarred rows; star, unstar, archive with a reason, restore, edit a row, Detect and Add harness. Not on iOS. Status: stable. Surface: web. Entry point: `#/harnesses`, `GET /v1/app/harnesses`. Tests: `tests/test_webapp_harnesses.py`.

Status: stable. Surface: CLI. Entry point: `swe setup [section] [--quick|--apply]`. Tests: `tests/test_setup_wizard.py`, `tests/test_setup_commands.py`, `tests/test_setup_apply_repeat.py`, `tests/test_setup_machine.py`.
- **First-run setup**: Clone your hub repo as `~/.swe`, which also installs every plugin the hub's marketplaces list and syncs its `mcp.json` servers into each harness ([#524](https://github.com/starship-terminal/swe/issues/524)); the CLI prints every row. Status: stable. Surface: CLI. Entry point: `swe setup --hub=<git url>`. Tests: `tests/test_setup_hub.py`, `tests/test_setup_hub_installs.py`.
- **First-run setup**: A setup window (agents, shared AGENTS.md, skills and MCP, look, notifications) reopened from Settings › General; its links step clones the hub repo (`swe setup --hub --json`) and shows only what didn't make it (a failed plugin or server, or a server waiting on a secret with its `swe mcp secret set` command). Status: stable. Surface: macOS. Entry point: first launch, Settings › General. Tests: `app/mac/Tests/SWECoreTests/FirstRunSetupTests.swift`.
- **First-run setup**: The setup page's step 2 clones the hub repo on the hub's thread while the page polls, and shows only what didn't make it. Status: stable. Surface: web. Entry point: `#/setup`. Tests: `tests/test_webapp_setup.py`.
- **Doctor**: Diagnose Node, npm and PATH issues that hide global installs plus registry and help drift; `--fix` runs the safe local fixes and checks again ([#529](https://github.com/starship-terminal/swe/issues/529)), `--fix=<check>` one of them; findings carry a source and remedies. Status: stable. Surface: CLI. Entry point: `swe doctor [--fix] [--json]`. Tests: `tests/test_doctor_fix.py`, `tests/test_doctor_fix_folds.py`, `tests/test_doctor_fix_mcp.py`, `tests/test_doctor_setup.py`, `tests/test_remedies.py`, `tests/test_path_health.py`.
- **Doctor**: Findings with their source line, remedy rows and a Fix-with-agent picker (launched through `/v1/sessions`); Fix all runs the ordered batch (setup, discover, init, `plugin-fix`) through `swe doctor --fix --json`, and every action `harness/doctor_fix.py` knows has a Run (`install`, `undeclare`, `marketplace-drop`, `plugin-reinstall`, `dangling-link`, `mcp-sync` one click per finding; newer ones through `swe doctor --fix=<check> --message=`). An action remedy's Run goes through `model.run(finding, action:)`, so an action a newer swe adds shows no Run. Status: stable. Surface: macOS. Entry point: Settings › General, Doctor cards. Tests: `app/mac/Tests/SWECoreTests/DoctorModelTests.swift`.
- **Doctor**: The same findings, remedies and agent picker, Fix all through `POST /v1/app/doctor/fix-all` and a Run per action; no sidebar entry. A Python test fails when either client misses an action. Status: stable. Surface: web. Entry point: `#/doctor`. Tests: `tests/test_webapp_doctor.py`, `tests/test_doctor_fix.py`.

## Sessions
- **Recent sessions**: A unified, time-sorted list of recent sessions across every agent swe reads, filtered by agent, folder (`--here`), text (title, path, agent, id, and transcript content when a search index exists) and local calendar dates (`-d N`, `-w N`, `-s`/`-e`). Status: stable. Surface: CLI. Entry point: `swe session [N]`. Tests: `tests/test_session_commands.py`, `tests/test_sessions_commands.py`, `tests/test_session_query.py`, `tests/test_session_json.py`, `tests/test_session_engines.py`, `tests/test_session_table_widths.py`, `tests/test_sessions_aggregator.py`.
- **Resume a session**: cd into a listed session's folder and resume it with its harness's own flags. Status: stable. Surface: CLI. Entry point: `swe session use <N>`. Tests: `tests/test_session_commands.py`, `tests/test_claude_handoff.py`.
- **Session picker**: Pick a session with the arrow keys; space reads its transcript, Enter resumes. Status: stable. Surface: CLI. Entry point: `swe session -i`. Tests: `tests/test_session_picker.py`.
- **Transcript search index**: Index agent transcripts so `--search` matches their content, see what the index holds, and choose whether the hub keeps it current. Owed: searching mirror copies of sessions the index never read. Status: stable. Surface: CLI. Entry point: `swe session index [--on|--off|--status]`. Tests: `tests/test_search_index.py`, `tests/test_search_writer.py`, `tests/test_search_harnesses.py`, `tests/test_search_containers.py`.
- **Session search**: Search the hub's sessions, transcripts first through its full-text index when present, then titles and folders as text; the index covers the hub machine only. Status: stable. Surface: API. Entry point: `GET /v1/search`. Tests: `tests/test_remote_search.py`.
- **Search satellite transcripts**: Match a satellite machine's transcripts too, not only its session details. Status: planned. Surface: API. Entry point: `GET /v1/search`. Tests: none.
- **Session history MCP server**: Expose recent sessions to an agent as an MCP tool (`get_recent_sessions`); needs the `server` extra. Status: stable. Surface: API. Entry point: `python -m swe.mcp_server`. Tests: `tests/test_mcp_server_entry.py`.
- **Transcript mirror**: Copy every Claude Code and Codex transcript into `~/.swe/data/transcripts/` while it exists (on by default) and never delete a copy ([#1918](https://github.com/starship-terminal/swe/issues/1918)); a session whose transcript the harness pruned lists as `mirrored` (`◇` in the ST column, `mirrored: true` and no `resume` in `--json`), and `swe report` and the transcript view read it from the copy. Owed: a size budget or keep-days. Status: stable. Surface: CLI. Entry point: `swe session mirror [--on|--off|--status]`. Tests: `tests/test_transcript_mirror.py`.
- **Transcript mirror**: The hub's loop and `swe session index` run a mirror pass from the same walk the search index uses. Status: stable. Surface: job. Entry point: `swe remote serve`, `swe session index`. Tests: `tests/test_transcript_mirror.py`.
- **Restore a mirrored transcript**: Put a mirrored session's copy back at the path its harness kept it (Claude project folder, Codex dated or archived path, account homes), by its `#`, id or Codex thread id, so it lists as live and `swe session use` resumes it; refused when any file is there, never overwriting. No Mac or web version yet. Status: stable. Surface: CLI. Entry point: `swe session restore <N|id> [--json]`. Tests: `tests/test_transcript_mirror_restore.py`.
- **Purge a mirror copy**: Delete one mirrored session's copies, `.shrunk-*` backups and manifest entries after listing the files and asking (or `--yes`); refused for a live session and for any file behind a symlink. swe has no session delete command, so this is the delete. No Mac or web version yet. Status: stable. Surface: CLI. Entry point: `swe session mirror --purge=<id> [--yes]`. Tests: `tests/test_transcript_mirror_restore.py`.
- **Mirror upkeep**: `swe doctor` reports the mirror (on or off, copies and bytes, orphans, the last pass, copies the manifest does not know, entries with no copy, stale temp files), and `--sweep-tmp` removes the temp files a crashed copy or restore left over a day ago. Status: stable. Surface: CLI. Entry point: `swe doctor`, `swe session mirror --sweep-tmp`. Tests: `tests/test_transcript_mirror_restore.py`.
